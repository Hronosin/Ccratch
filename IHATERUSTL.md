# IHATERUSTL

**I**nsane **H**armonic **A**mazing **T**rust **E**lementary **R**andom **U**nited **S**tandardized **T**emple **L**icense

> This is Scratch. It grew up, met RMS and understood that freedom matters
> most. The blocks are still sacred, though.

Legally, the IHATERUSTL is the [Mozilla Public License 2.0](LICENSE)
wearing a shrine maiden costume. Everything on this page is the costume:
the spirit of the thing, not its terms. The terms are in `LICENSE`.

## The spirit: an eye for an eye

- **Take the idea.** Ideas are free. Build your own block editor for
  Brainfuck, we will cheer. (No license can stop a clean-room rewrite
  anyway, and this one does not try.)
- **Take the code, keep the name.** Fork it, ship it, sell it: the authors
  stay credited, the files you changed stay open, under the same license.
  That is what the MPL asks, file by file.
- **Your own code next to it is yours.** Plugins, dialects, the program
  that uses libccratch: any license you like, closed ones included.
- **Take the code and wipe the name off.** Then the shrine maiden comes for
  a donation. (And, more to the point, so does the MPL.)

RMS is a little upset it is not the GPL. We said "GNU/Linux" three times
and he calmed down.

## The agreement

Ccratch also asks you to accept an End User License Agreement on first
run. It has seventeen points, about chaturanga, the 30th of February,
nasal demons and the year 2038, and none of them has any legal force.
Read it in the window (the `?` button) or with:

```sh
ccratch --eula            # in English
ccratch --eula --lang ru  # по-русски
```

костюме жрицы храма. Всё на этой странице — костюм, а условия — в `LICENSE`.

- **Берёшь идею — пожалуйста.** Идеи свободны, clean room никто не запрещает.
- **Берёшь код — оставь имя.** Форкай, распространяй, продавай: авторы
  указываются, изменённые файлы остаются открытыми под той же лицензией.
- **Твой код рядом — твой.** Плагины, диалекты, программы поверх
  libccratch — под любой лицензией, хоть закрытой.

RMS немного расстроен, что это не GPL. Мы трижды сказали «GNU/Linux», и
он смягчился.
